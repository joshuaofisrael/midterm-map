# Candidate image attribution

Portraits in `public/candidates/` come from [Wikimedia Commons](https://commons.wikimedia.org/). Each file below was re-checked against its Commons file page on **October 6, 2026** (license, author, and a pixel match to the stored file). Only public-domain files or Creative Commons Attribution (BY) / Attribution-ShareAlike (BY-SA) files are used. Public-domain status is as marked on the Commons file page. Candidates without a checked file show an initials avatar.

Changes are listed per file (resizing, format conversion, and square display crop). No other edits were made. On October 23, 2026 each stored portrait was saved as WebP. Files whose short side was wider than 320 pixels were reduced so the short side is 320 pixels. The square crop is still applied in the page layout. Adapted CC BY-SA images remain under the same license as the original.
